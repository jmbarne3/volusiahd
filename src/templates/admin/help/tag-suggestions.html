When someone registers and can't find the tag they want, they can type a new one. Those words wait in Tag suggestions for you to decide.

Approving a registration never waits on its tag suggestions. Decide them whenever suits you.

Deciding one

Open a suggestion and choose one of three things:

  • Approve — make a new tag if it's a useful word the directory doesn't have. It becomes a general tag and is added to that program. If a tag with the same name already exists, approving uses it rather than making a duplicate — the screen tells you when that's the case.
  • Use an existing tag instead if they meant something we already have ("Lego robotics" when we have "Robotics"). Pick the tag in that box and Save. The program gets the existing tag.
  • Reject if it isn't a tag at all — a sentence, a misspelling, something that belongs in their description.

You can approve or reject several at once from the list: tick them, choose the action, and press Run.

A tag is only useful if the same idea always gets the same word. When in doubt, use an existing tag.
