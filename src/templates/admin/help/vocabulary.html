Categories, tags and tag questions are how families narrow down the directory. They're also how the registration form decides what to ask.

Read this before changing anything here. The built-in vocabulary is reset every time the site is updated. That covers the thirteen categories, the tag questions and their answers, and the built-in tags, including which tags each category suggests.

So renaming a category, editing its description, or changing which tags it suggests will work, and then quietly undo itself at the next update. To make a lasting change to any of those, ask Jim, who changes it in the code.

What always lasts: new tags you create (including approved tag suggestions), programs, pages, search synonyms and submissions.

Categories

Categories are the headings across the top of the directory — Co-ops, Sports, Tutoring and so on. Every program has exactly one. The category a registrant picks decides which questions the form asks them, and which tags it suggests.

Tags

Tags are the finer detail: "Lego", "Spanish", "Competitive". A program can have as many as fit, and each tag has its own page listing every program that carries it.

  • Creating a tag: press Add tag, give it a name, and Save. Leave Group empty for an ordinary tag. New tags are general — offered under every category. These last.
  • Description: optional. It's shown at the top of the tag's page, so a sentence explaining what it means helps families.
  • Before creating a tag, search for one that already means the same thing. Two tags for one idea split the programs between them.

Tag questions

Tag questions are the multiple-choice questions on the registration form, like Ability level and Parent involvement. Each answer is a tag in that question's group, so families can filter by it.

  • Prompt is the hint shown under the question on the form.
  • Allows several decides whether people tick boxes or pick one.

These are part of the built-in vocabulary, so changes to them reset at the next update. Ask Jim for lasting changes.
