{% comment %} The filters, down the left edge. One form, posting back to whatever page it is on, so the same filters work on the all-programs page, a category page and a tag page. Everything it narrows by is a plain GET parameter, which means a filtered list is a link somebody can send to a friend. With the script running, every control applies the moment it changes and the Apply button hides itself — there is one way to search, not two. Without it the button is the way, and nothing else is lost. On a narrow screen the whole panel folds into a disclosure above the results, so a phone shows programs first and filters on request. {% endcomment %}

{% comment %} Near a place. The box is the registration form's address search, so a pick carries coordinates and costs no lookup; "Use my location" asks the browser and costs none either. The coordinates are not rendered as inputs: the script adds them from data-lat and data-lng and removes them the moment the box is edited, so a place typed over an old one never searches near the old one.
